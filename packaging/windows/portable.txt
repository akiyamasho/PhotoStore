PhotoStore portable mode

While this file sits next to photostore.exe, PhotoStore keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the PhotoStoreData folder beside it, and writes
nothing to %APPDATA%. Copy the whole folder to move PhotoStore with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\PhotoStore) instead.
If PhotoStoreData can't be written (for example on a read-only drive), PhotoStore says so and
uses %APPDATA%\PhotoStore instead.
