# PhotoStore 0.21.5

With a clip selected in the open video timeline, press **B** to switch to Brush or **V** to switch to Move. The tool changes immediately while the clip selection and playhead stay in place. Configured tool shortcuts, including alternate keys and Shift-cycling within a tool group, take priority over conflicting timeline shortcuts. [Issue #49](https://github.com/akiyamasho/PhotoStore/issues/49)

Click **Select** or **Razor** in the timeline to change clip editing modes. The timeline shortcut reference identifies which tool owns a shared key. **Enable / Disable Clip** continues to have no default shortcut.

QA used synthetic egui keyboard and pointer events on a disposable document. The Apple Silicon app and CLI use the local PhotoStore signing certificate.
