# PhotoStore 0.12.0

Status: published prerelease; reinstall and targeted New Document confirmation completed.

Published source: [`0ac6e812f1ded55e9a12c3a1fa0230c8fdbe3c6d`](https://github.com/akiyamasho/PhotoStore/releases/tag/photostore-recording-default-off-2026-10-11).
The final artifact was rebuilt from the tagged source and verified before publication.

PhotoStore 0.12.0 keeps recording off by default. In the New Document flow, `Record canvas
actions` is visibly unchecked until the user opts in. Existing recordings remain preserved. A
new disposable document opens with zero recorded frames; the screenshots establish these visible
states only and do not establish export correctness or full Photoshop parity.
