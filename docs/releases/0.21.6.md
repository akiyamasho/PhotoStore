# PhotoStore 0.21.6

Fixed a GPU compositor error that could switch PhotoStore to CPU while painting over video. The last tile of a video frame can be smaller than the compositor’s 256-pixel tile. PhotoStore now uploads only the pixels inside the destination texture, including when a placed frame starts partway through a tile.

The regression covers an 896 × 770 video frame with a blended paint layer, both at the canvas origin and after moving the frame. It compares GPU output against the CPU reference across the canvas, with whole textures and with paged textures.
