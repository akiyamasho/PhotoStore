# PhotoStore 0.15.0 — opacity stopwatches

Status: version and documentation prepared on the isolated `codex/opacity-stopwatch` branch.
Engine/native and timeline-UI opacity stopwatch work is implemented, and the required compiler gate
passed; screenshots, runtime, package, installation, and release evidence are pending. No production

The bounded pass adds ordinary-layer and Smart opacity stopwatches with sparse copy-on-write keys,
Linear/Hold interpolation, typed-property auto-key, previous/next markers, editable shortcut
bindings, and native backward-compatible persistence. The UI disable control removes keys only after
confirmation; an explicitly disabled direct API call deletes without a prompt. Existing coupled
video XY/opacity behavior is implemented and unchanged. Only independent video-opacity stopwatch UI
and migration remain future work. Full Photoshop parity, PSD temporal export, and audio acceptance
are not claimed.

(timeline capacity 1,000,000 frames), and a 64 MiB estimated property-snapshot limit. Smart Object
root curves preserve parent state through unpack/group operations. The compiler log is

pending.
