# PhotoStore 0.16.2

**Status:** Published stable on 2026-10-12 as [GitHub release v0.16.2](https://github.com/akiyamasho/PhotoStore/releases/tag/v0.16.2), release ID `RE_kwDOVDxG7c4YeXjs`, from exact source/tag SHA `a7a2dd6c306d2f4ce33bd3a6fe87044cac03d520`. The source fixes and accepted timelapse fallback are delivered. Runtime and GUI acceptance remain untested.

## Changes

- Fill, Pen, and Lasso use dedicated original toolbar glyphs with tint and DPI-aware rasterization.
- Escape resets an idle canvas view through the existing reset path while preserving ordinary cancel,
  text-edit, and modal priority; zoom and center are unchanged.
- Clone Stamp exposes the current hover/candidate sampled region with canonical mapping and a
  first-stroke source marker. The user-confirmed Aligned mode keeps its intentional fixed
  source/destination offset, so the source follows the pointer after release; no changed Aligned
  behavior is claimed.
- `tools.moveAutoSelect` persists across restarts and both theme bars and Move tool presets, with
  default `true`.
- Timelapse remains off by default under the accepted fallback. Encoded recording can retain up to
  256 MiB per document; raw RGBA8 alone is approximately 7.91 MiB per 1920×1080 frame and 31.64 MiB
  per 3840×2160 frame before other buffers. No representative RSS measurement was run, so no
  guaranteed low-memory threshold or automatic enablement is claimed.
