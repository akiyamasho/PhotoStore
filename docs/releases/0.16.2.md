# PhotoStore 0.16.2

**Status:** Release source preparation. The source fixes are implemented and the accepted timelapse
fallback is documented. The required final ARM64 compiler/build, package verification, local
installation, and publication evidence are pending this release transaction. Runtime acceptance is
not claimed.

## Changes

- Fill, Pen, and Lasso use dedicated original toolbar glyphs with tint and DPI-aware rasterization.
- Escape resets an idle canvas view through the existing reset path while preserving ordinary cancel,
  text-edit, and modal priority; zoom and center are unchanged.
- Clone Stamp exposes the current hover/candidate sampled region with canonical mapping and a
  first-stroke source marker. The user-confirmed Aligned mode keeps its intentional fixed
  source/destination offset, so the source follows the pointer after release; no changed Aligned
  behavior is claimed.
- `tools.moveAutoSelect` persists across restarts and both theme bars and Move tool presets, with
  default `true`.
- Timelapse remains off by default under the accepted fallback. Encoded recording can retain up to
  256 MiB per document; raw RGBA8 alone is approximately 7.91 MiB per 1920×1080 frame and 31.64 MiB
  per 3840×2160 frame before other buffers. No representative RSS measurement was run, so no
  guaranteed low-memory threshold or automatic enablement is claimed.

## Evidence boundary

The integrated pre-release source commit `d4cd1c035d1e43a74ef4b594056e7cc71199b78e` passed
`cargo check --locked --offline -p photostore --features dev-install` using the shared target,
one Cargo job, Rayon one, and `nice -n 10`; receipt:
`/tmp/photostore-sweep-check-final-20261012.log`. The 0.16.2 version bump changes package metadata,
so the release transaction requires one final app-plus-CLI ARM64 build from the new exact source
SHA. No separate preview build, extra compiler check, screenshot pass, runtime acceptance, or
release claim is made here.

The final artifacts are the local ARM64 PhotoStore app and CLI pair. Existing 0.16.1 screenshots
and their evidence remain historical references; no new 0.16.2 screenshot is required for this
ordinary bug-fix release.
