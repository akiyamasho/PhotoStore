# PhotoStore 0.18.3 — Selection-scoped Generative Fill context bar

Status: **release preparation**. This receipt will be finalized after the single ARM64 macOS
production package is built, verified, published, and installed from the exact source commit.

This release adds a selection-only, non-modal Generative Fill context bar. `Command-K` now opens
the selection-scoped bar when a document and selection are available; the command is guarded when
either is missing. Settings no longer owns Cmd+K by default; custom shortcut assignments retain
precedence. Setup retry remains available from the context bar and the
document/selection guards prevent invalid invocation.

Related issue: [#22](https://github.com/akiyamasho/PhotoStore/issues/22).
