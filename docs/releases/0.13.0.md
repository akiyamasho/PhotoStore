# PhotoStore 0.13.0 — tool shortcuts and marquee selection

Status: published prerelease; source implementation and compiler evidence are complete. Required check: 34.02 seconds, log
`/private/tmp/photostore-tool-shortcuts-check-20261011.log`.

The pass gives each tool and subtool an editable primary and alternate shortcut, supports shared
tool keys, clear/default actions, deterministic sorting, native JSON export/import drafts, and keeps
existing `.kys` import. Rectangular Marquee is the initial marquee tool in a fresh configuration.
With Shift switching enabled, pressing a shared tool key keeps the current bound subtool; Shift cycles
only among subtools still assigned to that key. Clearing Elliptical Marquee leaves M assigned only to
Rectangular Marquee. Clearing Background Eraser and Magic Eraser leaves E assigned only to Eraser.
Existing explicit Use Shift Key for Tool Switch settings are preserved. These changes do not claim
Photoshop parity or KYS export.

[#2](https://github.com/akiyamasho/PhotoStore/issues/2). Planned tag:
