# PhotoStore 0.21.1

The Pages dialog now keeps a vertical list of page thumbnails and places the move controls below it. Japanese labels are available for page navigation and search.

Choose **Notebook** in the Layers panel or **View → Notebook** to work with an existing PSD a page at a time. Each root layer or group is a page. Nested layers stay inside their group. The canvas uses the active page for drawing and opt-in recording. Hidden layers keep their saved visibility.

Use **⌘⇧X** for the previous page, **⌘⇧C** for the next, and **⌘K** to open Pages. Search by number or name and press Enter to jump. Select a row and choose **Move up** or **Move down** to change its position in the layer stack. Edit → Undo reverses a move. Navigation uses per-document session state and saving keeps the full document.

The Apple Silicon app and CLI use the local PhotoStore signing certificate. Apple notarization is unavailable for this signing identity. [Download the release](https://github.com/akiyamasho/PhotoStore/releases/tag/v0.21.1).
