# PhotoStore 0.20.9

**File → Save** and **⌘S** save eligible single-layer JPEG and PNG documents back to their original path and format. PhotoStore checks the source format and uses its atomic writer for the update. Files with extra layers, editable layer properties, animation, or transparency that JPEG cannot preserve use the Save As workflow.

Two focused regressions exercised same-path PNG and JPEG encoding after an edit and the layered JPEG Save As behavior.

The Apple Silicon macOS release includes the standard PhotoStore app and CLI. Both use the persistent local PhotoStore signing certificate. Download the artifacts from [GitHub Releases](https://github.com/akiyamasho/PhotoStore/releases/tag/v0.20.9).

See [issue #39](https://github.com/akiyamasho/PhotoStore/issues/39) and the [Save workflow design](../design/2026-11-21/direct-image-save/prompt.md).
