# PhotoStore 0.20.7 — stable preview layout and lower buffering cost

**Status: pushed, published and atomically installed as the normal app/CLI.** [Stable v0.20.7](https://github.com/akiyamasho/PhotoStore/releases/tag/v0.20.7) targets exact binary source `7c17226b4e0989a55a32c963ae4f39b63afd1054`. - **#23:** fixed-width preview status keeps the toolbar and timeline origin stable as frames become ready. Ordinary requests do not flash a buffering indicator. Paused linked-video completion uses the background presenter, which now wakes the event loop immediately. Transport can enqueue the next clock-selected preparation in the same paint as a completion.
- Invisible/out-of-range/muted linked movies and nested Smart Object sources under hidden ancestors share the same decode/readiness predicate. Hidden media does not consume foreground preparation or block the visible frame.
- Retained sequential decoders keep their worker affinity while queued/running/warm. The affinity table is bounded and retired with actual stream ownership; queue pressure does not move a warm stream to another worker.
- Four reusable raw frame buffers replace repeated large decode/skip allocations. They match the existing session allowance; memory settings are not increased.
- Eligible positive axis-aligned reductions decode linked movies at their placed dimensions during preview, then preserve document geometry through an adjusted sampling transform. Checked fingerprints/original metadata, integral dimensions/translation and bounded ratio normalization guard this path. Integer translations bypass bicubic warping. Arbitrary/projective/fractional transforms retain full-source evaluation. Explicit output/rasterization retains original-source quality and the persisted source placement.
- Identity placement avoids repeated exact pixel-bound scans in readiness and synchronization; eligible reduced frames also skip the scan when their effective placement is identity. The RGB24 path returns an already-correct RGBA8 surface without cloning its tile map.
- Readiness avoids duplicate working-space conversion. Full-source frames still validate their real decoded footprint; reduced frames validate trusted original geometry.
- **#30:** a Hand gesture starting late no longer pans from an old press origin. Captured pans last until pointer release; a new Space chord cannot steal an active drawing gesture's Up event.
- **#31:** a delivered pen secondary press is routed by its own position and topmost layer rather than requiring a preceding hover event. Canvas overlays, text, erase preference and Alt brush resize retain their behavior.

Completion counts only real copies, so sleeping helpers are outside the critical path; concurrent callers retain their own bounded batch.
