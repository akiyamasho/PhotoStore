# PhotoStore 0.18.2 — Linked movie footage and brush curves

Status: **release metadata prepared; build, publication, and installation pending**. Planned tag
`v0.18.2` targets the reviewed source commit. Release date: 2026-10-25. Scope is the ARM64 macOS
app and CLI.

Movie opening and **New Video Layer from File** now keep the original movie linked and decode only
the first frame during import. Later frames use an asynchronous bounded preview cache with a
160 MiB frame budget; the source movie must remain available for later playback and export. Native
document format version 2 stores linked movie metadata. Version 2 readers continue to read version 1
files; older PhotoStore builds that only read version 1 refuse version 2 documents. **Frames to Layers** remains an eager conversion with its
existing 512 MiB decoded-frame limit.

Brush smoothing reconstructs sparse sampled curves while retaining the input pressure and timing
data. It applies to the shared live stroke path for tablet and mouse input; exact native tablet and
mouse input behavior has not been manually verified for this release.

Related issues: #18, #19, #20.
