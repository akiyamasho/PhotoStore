# PhotoStore 0.18.2 — Linked movie footage and brush curves

Status: **published stable release**. Tag `v0.18.2` points to source commit
`142f4704f5f9645d56d35208e75fdae12aa27246`, published on 2026-10-25 for ARM64 macOS.

Opening a movie or using **New Video Layer from File** keeps the movie linked and decodes only its
first frame during import. Later preview frames load asynchronously through a bounded 160 MiB frame
cache. Keep the source file available for later playback and export. Native format version 2 stores
linked movie metadata; version 2 readers continue to read version 1 files, while older PhotoStore
builds that only read version 1 refuse version 2 documents. **Frames to Layers** remains an eager
conversion with its existing 512 MiB decoded-frame limit.

Brush smoothing reconstructs sparse curves while retaining pressure and timing data on the shared
live stroke path. Exact native tablet/mouse input and the reporter's MP4 and OS-drag timing were not
manually reproduced. No CapCut performance parity is claimed.

Related issues: #18, #19, #20, #21.
