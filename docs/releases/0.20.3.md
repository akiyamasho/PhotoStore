# PhotoStore 0.20.3 — layer workflows and canvas input

**Status: published and installed.** [Stable v0.20.3](https://github.com/akiyamasho/PhotoStore/releases/tag/v0.20.3) targets exact source
[`e7de47f6b1103ee32f8bbb6b06daee8054c04473`](https://github.com/akiyamasho/PhotoStore/commit/e7de47f6b1103ee32f8bbb6b06daee8054c04473). The normal ARM64 app and CLI
were built locally once, packaged, verified and atomically installed from those same published
artifacts. Native shortcuts, drag/drop, pan feel and Cintiq input acceptance remain manual.
Documentation-only receipt commits do not rebuild or move the immutable source tag.

- Cmd+R duplicates directly in the same document. Cmd+Ctrl+R opens Copy Layer, choosing the
  destination document, insertion layer and optional name. Cmd+Shift+R remains Lens Correction;
  the Rulers default moves to Cmd+Alt+Shift+R and timeline speed's conflicting default is removed.
- Drop a movie on an open document to add a linked video layer. It remains static until a Video
  Timeline is explicitly created, preserving source metadata and deferred audio across native
  save/reopen. Existing Video timelines receive playable ranges/audio. Multiple drops serialize
  against captured document identities. Explicit File Open and tab-strip drops retain their paths.
- Space+drag updates the view before painting and captures movement from the actual press;
  canvas-owned Space no longer toggles timeline transport. Pan bounds use the displayed camera.
- Brush/Pencil/Eraser secondary press opens the existing picker immediately despite hover jitter,
  retains resize/erase/layer-pick gestures, guards its own opening press from dismissal and consumes
  the remaining button/contact gesture without stray marks.

Native keyboard, drag/drop, pan feel and Cintiq Pro Pen acceptance remain manual. The input fix
handles delivered secondary events and does not alter Wacom drivers/profiles. The optional deferred
playback flag uses existing v3 serialization; old readers can ignore the new intent. Other codec,
resource, Smart and archive limits remain as documented in 0.20.2.
