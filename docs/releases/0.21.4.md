# PhotoStore 0.21.4

- **V selects Move** with the default tool mapping, including after selecting a video or audio clip. Enable / Disable Clip is unbound by default and remains available in Keyboard Shortcuts. [Issue #45](https://github.com/akiyamasho/PhotoStore/issues/45)
- **Escape follows keyboard focus.** Click the canvas to use Escape for canvas editing, or click the timeline to clear its selection. Timeline redraws skip shortcut lookup when there is no keypress. [Issue #46](https://github.com/akiyamasho/PhotoStore/issues/46)
- **Video timeline zoom stays set through 16×.** Command-wheel zoom follows the pointer on the time axis, and horizontal scrolling follows the trackpad direction. [Issue #47](https://github.com/akiyamasho/PhotoStore/issues/47)
- **The ruler and tracks follow the transport clock** while the video preview is catching up. Paused edits and seeks use the document frame. [Issue #48](https://github.com/akiyamasho/PhotoStore/issues/48)

Eight focused tests passed using synthetic egui key and wheel events and rendered timeline geometry. They covered visual and audio selections, custom bindings, text focus, Escape, Delete, frame stepping, panned zoom and playhead alignment with a delayed decoded frame. Physical keyboard and trackpad input were outside this test run.

The Apple Silicon app and CLI use the local PhotoStore signing certificate. Apple notarization is unavailable for this certificate.
