# PhotoStore 0.21.7

Large layered projects reuse verified raster tiles when opening a native document. Edited tiles detach on write. Animated Smart Objects share the media cache according to their estimated resident size, and independent nested videos can request their frames in the same presentation pass. Embedded animations without linked movies can reuse a completed composite at the same time. Nested linked movies retain their existing source validation.

The Metal compositor can batch eligible Normal stacks of up to 256 sources. It skips layers clipped outside the current cell, keeps unchanged raster textures resident within the configured budget, and checks the upload budget before staging each cell. Mixed blends continue through the general GPU renderer. Nested CPU compositing writes in bands to reduce temporary allocations.

The load fixtures and native measurement tool are in [scripts](../../scripts/). They exercise 4K documents with embedded animated compositions, nested movies and stills, independent top-level movies and over 100 layers. They also measure visible frame publication and check Brush and Move with the timeline open.
