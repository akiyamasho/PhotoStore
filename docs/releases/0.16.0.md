# PhotoStore 0.16.0

**Status:** Release source and screenshot evidence prepared for v0.16.0; preview compiler and screenshot legibility checks passed. Final artifacts and publication status are recorded on the [GitHub release](https://github.com/akiyamasho/PhotoStore/releases/tag/v0.16.0).

This candidate brings together the previously documented close-safety and timeline-persistence work, ordinary-layer Position and Opacity animation, and independent Position and Opacity tracks for video layers. Native shortcut-file autosave, the consolidated `./dev` workflow, and guarded local promotion are also included in the source history. This release does not establish full Photoshop, Smart Object, PSD, affine-transform, or audio parity.

## Changes

- **Close safety and timeline persistence (0.14.0):** Canceling the unsaved-document guard leaves the document open. A saved video timeline can be reopened and inspected. Historical preview captures retain their original 0.14.0 provenance.
- **Ordinary-layer animation (0.15.0–0.16.0):** Adds sparse opacity keys, Linear/Hold interpolation, auto-key from typed opacity edits, timeline markers, and independent raster Position animation with typed XY values. The earlier hidden 0.15.0 capture attempt produced no image and is not reused; the new 0.16.0 raster preview capture documents the current Position and Opacity controls.
- **Video Position and Opacity (0.16.0):** Adds separate owned tracks for video-layer translation and opacity. Position uses bounded whole-pixel XY keys; opacity migration preserves existing curves and snapshots within documented limits. The legacy coupled XY/opacity behavior remains available when independent tracks are not enabled. The screenshot also shows the legacy keyframe ownership guidance when an owned track is active. Detailed implementation and runtime limits remain in the [goal ledger](../photostore-goal-ledger.md).
- **Shortcut and development workflow:** Native shortcut-file autosave and the consolidated `PhotoStore-dev` watcher are documented with historical capture provenance in [0.13.1 evidence](../screenshots/0.13.1/evidence.md). Local CI promotion is guarded and opt-in; this release pass does not claim that it enabled the watcher.
