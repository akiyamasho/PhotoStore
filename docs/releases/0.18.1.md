# PhotoStore 0.18.1 — Media timeline and swatch improvements

This release adds desktop import for H.264 video in MP4 and MOV containers, plus MP3 and WAV audio
clips. Opening a video creates a timeline video layer and links its embedded audio when present;
opening audio creates a timeline document with an audio clip. Media decoding uses the existing
FFmpeg/ffprobe backend and requires those tools to be available on the desktop.

Swatches can be reordered by dragging them within a group or into another group. The release asset
retention workflow keeps downloadable assets for the three newest published releases and removes
assets from older releases while preserving their release records and tags.
