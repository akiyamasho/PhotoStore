# PhotoStore 0.21.2

Use **Actions → Video → Clear Time-lapse History…** to remove the active document's recorded frames after confirmation. The artwork and recording setting are preserved; save the document to persist the change.

Video export now makes replacement consent explicit for the displayed output and resets it when the output or format changes. Confirm replacement in the PhotoStore export form even if the native save dialog also asked. Image sequences identify the numbered output pattern. Existing files remain protected when replacement is not selected.

Time-lapse recording avoids copying its growing frame index on every edit. This addresses a concrete source of increasing overhead when recording is enabled; the cause of the reported drawing hang remains under investigation.

The Apple Silicon app and CLI use the local PhotoStore signing certificate and are not notarized by Apple. [Download the release](https://github.com/akiyamasho/PhotoStore/releases/tag/v0.21.2).
