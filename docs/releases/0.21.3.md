# PhotoStore 0.21.3

Canvas cropping now supports documents with video layers. The crop keeps linked media linked and shifts video placement with the canvas; resident video frames move with it. Video pixels outside the canvas remain intact, including when cropped pixels are deleted from ordinary raster layers. Rotated crops with video layers are not yet supported and return an error before changing the document.

This release includes the clear time-lapse history action and export confirmation changes from [0.21.2](0.21.2.md). Video playback and PSD save/reopen after cropping have not yet been manually verified.

The Apple Silicon app and CLI use the local PhotoStore signing certificate and are not notarized by Apple. [Download the release](https://github.com/akiyamasho/PhotoStore/releases/tag/v0.21.3).
