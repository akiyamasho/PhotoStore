# PhotoStore 0.16.1

**Status:** Implemented in source commit `501739c5fdfd022270f130d6877f9b171d937007`. At screenshot capture time, the disposable 0.16.1 preview was captured for review; the user confirmed the resize fix works. Tag and publication status are tracked separately from this preview record.

## Change

Free Transform now resizes selected pixels without a modifier. Hold Shift to preserve the transform's current aspect ratio, including when shrinking along only one axis. Lasso canvas events continue through an active transform so its handles receive drag movement and release. Existing command-modified distort/skew/perspective behavior and Alt, rotate, and move modifiers are retained.
