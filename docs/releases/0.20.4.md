## Focused evidence

The installed 0.20.3 CLI reproduced a synthetic stale-snapshot opacity edit reverting from 0.5 to
0.0 on the next frame. The final 0.20.4 CLI preserves 0.5 across frames 1 and 20 with two linked
videos visible and independent movie-audio owners. Audio-layer native roundtrip, duplicate,
same/cross-document copy with untouched source, delete/undo and owner-range timing passed.
Untrusted automation rejects both the new audio importer and multi-source measurement before
reading ambient paths. These are focused data/permission checks on the shipped binary, without
another compiler/test build or broad QA suite.

On the Apple M1 Max / 32 GiB host, six distinct source paths reference the same owned synthetic
3840×2160/30 fps H.264 fixture bytes. Each source uses a separate cache identity; all sources
returned 60 distinct sampled frame hashes, with visibility and opacity preserved and history/clean
state unchanged. The measurement excludes GPU composition, display, input and audio output.
Its rate is **not native playback FPS**; it does not establish CapCut-like performance.
Six original-resolution sources remain below a 30 fps preparation target, so #23 stays open.
