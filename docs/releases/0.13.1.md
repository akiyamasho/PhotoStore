# PhotoStore 0.13.1 — development watcher, shortcut exchange, and local CI

Status: implemented and preview verified; final package verification and stable publication follow
the exact tagged source SHA.

This patch records the landed development watcher and isolated `PhotoStore-dev` installation, the
tool icon and shortcut work, native shortcut-file autosave, and the opt-in local CI boundary. New
trusted `main` commits update the isolated dev installation, while only a published, non-draft,
non-prerelease GitHub Release may promote production. The loop uses incremental builds and guarded
owned-process restarts, defers while any document tab, background job, or dialog is active, and
does not claim in-process hot module replacement or Photoshop parity.

Release tag: `v0.13.1` will point to the final documentation-and-source commit. The stable release
will contain the locally built Apple Silicon macOS ZIP and `SHA256SUMS`; the build is ad hoc signed,
not notarized, and does not claim universal, CLI, or all-platform expansion.

The committed evidence is [toolbar-shortcut-autosave.png](../screenshots/0.13.1/toolbar-shortcut-autosave.png).
It records the tool icons and shortcut-file autosave UI from preview source
`34c70481c3a1602bc80931d302ce8e5def2c5f6e`, with a blank 8×8 demo document. The capture is legible
and contains no private artwork; its clipped OS title, full build SHA, and path tail are documented
in the [evidence record](../screenshots/0.13.1/evidence.md). The final package must be rebuilt from
the exact tagged source SHA before publication, and local CI may defer installation while the owner
production app is running.
