# PhotoStore 0.13.1 — development watcher, shortcut exchange, and local CI

Status: source and documentation preparation. Compiler, preview build, screenshot evidence,
release publication, final artifact verification, and installation evidence are pending.

This patch records the landed development watcher and isolated `PhotoStore-dev` installation, the
tool icon and shortcut work, native shortcut-file autosave, and the opt-in local CI boundary. New
trusted `main` commits update the isolated dev installation, while only a published, non-draft,
non-prerelease GitHub Release may promote production. The loop uses incremental builds and guarded
owned-process restarts, defers while any document tab, background job, or dialog is active, and
does not claim in-process hot module replacement or Photoshop parity.

Planned release tag: `v0.13.1` (subject to the final source SHA and release review). No tag,
package, screenshot, or published-release claim is made by this document.

The required release evidence is a real PhotoStore screenshot of the dev-watch flow using a
disposable demo document, stored under `docs/screenshots/0.13.1/` with an evidence record. The
compiler and preview build must precede capture; the final package must be rebuilt from the exact
tagged source SHA before publication.
