# Notebook View

Generated on 2026-11-21 with built-in GPT Image. No reference images. All artwork and interface imagery were generated for this design. Project asset under the repository's MIT or Apache-2.0 terms.

The design shows a single editable page, a compact Layers / Notebook switch, previous and next controls, and a Pages dialog. Use the native editor's existing tools, theme and dock. In the dialog, keep the current page identifiable by name and number. Allow selecting a page and moving it up or down in the PSD root stack. Use existing layer icons or thumbnails. Confirm a jump with Enter or a direct activation. Reorders are immediately undoable document edits.

The interaction reference was the quick page navigation and rearrangement described in the [MyScript Notes notebook guide](https://help.myscript.com/notes/overview/notes/).
