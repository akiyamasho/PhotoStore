# Smart Filter Masks milestone

PhotoStore's 0.8.0 pass added Smart Filter mask targeting and controls. The public behavior reference is Adobe's [Smart Filter mask documentation](https://helpx.adobe.com/photoshop/desktop/effects-filters/smart-filters/mask-smart-filter-effects.html).

The source implementation supports mask targeting and filtering, grayscale mask view, density and feather controls, invert, automatic white-mask creation, and corresponding UI controls. Live previews target the mask; the composite filtered effect refreshes at a committed stroke. This does not claim full live effect recomposition. It preserves the distinction between the filter target and the mask target.

The current 0.9.0 source pass adds `copyFilterMask` and `moveFilterMask` with same-document ID guards, effective inherited-lock checks, copy-on-write copying, a default `overwrite=false`, one atomic undo edit, and self-transfer no-ops. Plain mask dragging moves; Option-drag copies; named destinations and explicit overwrite prompts are supported. Normal, Shift, Option, and Command thumbnail semantics remain intact. Filter-mask channel sources use `ChanRef` strings for selection, Apply Image/Calculations inputs, and duplicate alpha channels. Channel documents use open-document indexes, while transfer and property guards use document IDs. The temporary Filter Mask row supports scoped normal targeting, overlay/gray eyes, footer load/delete, and exits filter view when an ordinary channel is selected. Apply Image grayscale targets route to masks rather than pixels. Generic UI routing injects only the target.

Video keyframe controls now preserve typed x/y/opacity values until Set, interpolate initial values, enforce layer/document guards and present-invalid errors, sample defaults for omitted values, use document timeline bounds, cap duration at 100000, and store/sync atomically with no-op Set/Delete behavior. A narrow target-aware dispatcher precondition and a history-based UI cache avoid full per-paint track hashing; coalesced external key edits remain unverified. Exact Photoshop UI parity, unknown PSD filter behavior, full transform/style tracks, sparse tracks, and broad acceptance remain open.

The related New Document fix accepts the recording field through strict parameter validation and keeps the form with an inline error when Create fails. Movie reload preserves interpretation and playback settings, while canonical audio reprobe and valid split envelopes are retained. The 0.8.0 native app/CLI HEIF compiler check passed; the final gate is recorded in `/private/tmp/photostore-smart-mask-newdoc-check-20261011-final.log` (exit 0 in 4.27s). This source was packaged and installed in the 0.8.0 prerelease; exact UI parity and broad visual acceptance remain unverified.

The 0.9.0 native app/CLI HEIF compiler check passed first in 12.18 seconds and finally in 3.71 seconds after the transfer chooser UI changes. The final log is `/private/tmp/photostore-mask-channels-keyframes-check-20261011-final.log`. The source was then packaged, published, and installed as the 0.9.0 prerelease; no broad UI or Photoshop parity claim is made.
