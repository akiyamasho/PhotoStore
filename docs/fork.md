# PhotoStore fork provenance

PhotoStore is a fork of [PhotoCraft](https://github.com/storytold/photocraft), customized for personal use and workflows. The independent private repository is [akiyamasho/PhotoStore](https://github.com/akiyamasho/PhotoStore); it has no upstream sync relationship.

Original source history, authorship, licenses, notices, and attribution records are preserved. PhotoCraft names remain only where they identify original contributors, historical source material, or immutable upstream references.
